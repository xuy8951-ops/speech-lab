# speech-lab 项目说明书

> 文档日期：2026-11-03  
> 项目地址：https://github.com/xuy8951-ops/speech-lab  
> 当前口径：已完成 S0、S1 和 S2 小规模真实数据实验（v1—v5）。新增三说话人验证集已在本机冻结，但尚未完成复评，因此不计入正式实验结论。

## 1. 项目是什么

speech-lab 是一个语音增强研究项目。它要解决的问题是：一段语音里混有噪声，算法能否在尽量保留人声的前提下，把噪声降低。

项目的长期方向是：

```text
传统数字信号处理 → 小型神经网络 → 预训练模型迁移 → 中文真实场景
```

当前已经完成的是前两个阶段，以及真实英文公开数据集上的小规模对照实验。**目前还没有完成中文真实场景训练，也没有进入预训练大模型迁移阶段。**

这个项目目前是一套可运行、可复现的研究代码，不是已经打包好的商业降噪软件。

## 2. 目前已经完成的成果

### 2.1 S0：统一研究框架与传统基线

已经搭好以下基础能力：

- 统一的 `Enhancer` 模型接口；
- 按名称创建模型的注册表；
- 每次实验对应一个 YAML 配置文件；
- 谱门控传统降噪基线；
- 合成测试数据与固定随机种子；
- 逐样本 `scores.jsonl` 和分组 `summary.csv` 评测输出；
- STFT 可逆性、混合 SNR 等单元测试。

谱门控基线的结果说明了传统方法的适用边界：

| 噪声类型 | 输入 SNR | 输出 SNR | 提升 |
|---|---:|---:|---:|
| 白噪声 | 0 dB | 8.270 dB | +8.270 dB |
| 白噪声 | 5 dB | 12.596 dB | +7.596 dB |
| 粉噪声 | 0 dB | 1.514 dB | +1.514 dB |
| 类人声噪声 | 0 dB | 0.000 dB | +0.000 dB |

结论：谱门控对白噪声有效，但对复杂噪声，尤其是类人声噪声，基本无效。这是引入神经网络方法的原因。

### 2.2 S1：小型 GRU 模型与训练链路

已经实现 `tiny_gru`：

- 参数量：659,713；
- 结构：双向 GRU；
- 输入：带噪语音的短时傅里叶幅度谱；
- 输出：每个时频点的掩蔽；
- 增强方式：预测掩蔽 × 带噪幅度，再沿用带噪相位重建波形。

通用 Trainer 已支持：

- 可变长度音频组成 batch；
- padding 位置不参与损失；
- 训练日志；
- 验证集评估；
- 最佳权重保存；
- 验证早停；
- 断点续训。

过拟合冒烟实验中，训练损失由 1.093 降至 0.190，训练样本 SNR 平均提升约 8.8 dB，但未见样本只提升约 1.99 dB。这说明训练链路能够学习，同时也直观展示了泛化差距。

### 2.3 S2：VoiceBank-DEMAND 真实数据实验

已完成：

- VoiceBank-DEMAND 数据下载与清洗脚本；
- 16 kHz、单声道、float32 成对音频处理；
- 训练、验证、测试 manifest；
- 824 条官方测试样本冻结及 SHA-256 校验；
- STOI 指标接入；
- 验证集早停与正式测试评测；
- v1—v5 五组受控实验。

当前正式结果均来自同一个 824 条冻结测试集。训练侧仅使用 128 条样本，因此这些结果属于小规模 CPU pilot，不能与全量训练结果或 SOTA 直接比较。

## 3. v1—v5 实验结论

| 版本 | 核心变化 | SNR 增益 | SI-SDR 增益 | STOI 变化 |
|---|---|---:|---:|---:|
| v1 | 单训练说话人，幅度 L1 | +1.197 dB | +1.296 dB | -0.036 |
| v2 | 两个训练说话人，幅度 L1 | **+5.522 dB** | **+5.306 dB** | -0.032 |
| v3 | 幅度＋对数幅度损失 | +5.030 dB | +4.763 dB | -0.038 |
| v4 | 直接 IRM 监督 | +4.557 dB | +4.576 dB | **-0.014** |
| v5 | 幅度＋0.25 × IRM 损失 | +5.304 dB | +5.143 dB | -0.030 |

### 3.1 v2：目前最高的 SNR

v2 在不增加训练条数的情况下，把训练说话人从一个增加到两个，波形级指标明显改善。

这说明在当前小数据设置下，训练说话人多样性是有效的。但它仍然使 STOI 平均下降 0.032，因此不能把“SNR 更高”直接等同于“人声更容易听懂”。

### 3.2 v3：一次保留记录的负结果

加入对数幅度损失后，SNR、SI-SDR 和 STOI 都没有超过 v2。该结果没有支持“对数幅度项能够保护弱语音并改善可懂度”的假设。

负结果同样有价值：它排除了一个在当前设置下无效的方向，避免后续重复投入。

### 3.3 v4：目前最好的 STOI 保持能力

相位 oracle 诊断表明，即使沿用带噪相位，理想掩蔽仍能明显提高 STOI。因此当前主要问题是掩蔽预测质量，而不只是相位。

v4 改为直接学习理想比例掩蔽后：

- STOI 变化由 v2 的 -0.032 改善到 -0.014；
- 824 条中有 634 条的 STOI 优于 v2；
- 但 SNR 增益由 5.522 dB 降到 4.557 dB。

所以 v4 是“更好地保持可懂度”，不是“所有指标都更好”。

### 3.4 v5：接近 v2，但没有综合超越

v5 试图组合 v2 和 v4 的优势，采用：

```text
总损失 = 幅度 L1 + 0.25 × IRM L1
```

它的 SNR 接近 v2，但 STOI 没有保住 v4 的优势。当前仍然是：

- **v2：最高 SNR；**
- **v4：最佳 STOI 保持能力；**
- **v5：一个接近 v2 的折中版本，不是新突破。**

## 4. 如何理解三个主要指标

### SNR

信噪比。数值越高，通常说明噪声相对更少。项目重点看 `delta_snr`，即增强后比增强前提高了多少 dB。

### SI-SDR

尺度不变信号失真比，也是衡量波形重建和干扰抑制能力的指标。一般同样越高越好。

### STOI

短时客观可懂度，用来估计语音是否容易被人听懂。项目重点看增强前后的差值：

- `delta_stoi > 0`：可懂度提高；
- `delta_stoi = 0`：基本不变；
- `delta_stoi < 0`：可懂度下降。

当前所有正式版本的平均 STOI 变化仍为负，所以项目还没有解决“降噪后更可懂”的问题。

```text
├── runs/                     # 本地实验输出，不上传 GitHub
└── docs/log/                 # 每周研究日志
```

## 6. 一次实验怎样运行

```text
读取 YAML
   ↓
根据名称创建数据集和模型
   ↓
加载训练集、验证集
   ↓
训练并保存验证损失最佳的 best.pt
   ↓
加载 best.pt
   ↓
在冻结测试集上增强
   ↓
输出 scores.jsonl 与 summary.csv
```

两条主要命令为：

```bash
python train/run.py configs/exp/003_gru_voicebank_multispk.yaml
python eval/run.py configs/exp/003_gru_voicebank_multispk.yaml
```

只评测验证集时：

```bash
python eval/run.py configs/exp/006_gru_voicebank_mag_irm.yaml --split val
```

运行全部测试：

```bash
python -m pytest tests/ -q
```

最近一次已核验结果为：`7 passed`。新增的三说话人验证集冻结脚本是在此后加入的，后续仍需重新执行完整测试。

## 7. 实验输出怎么看

每次评测主要生成：

- `scores.jsonl`：一行一个样本，记录该样本增强前后的指标；
- `summary.csv`：按语言、噪声类型和输入 SNR 分组汇总；
- `summary.csv` 最后一行 `all,all,all`：全体样本的总体结果。

训练目录还可能包含：

- `best.pt`：验证损失最佳的模型权重；
- `last.pt`：最后一轮权重；
- `trainer_state.pt`：恢复训练所需状态；
- 训练日志和配置快照。

## 9. 当前限制

1. **语言限制**：当前真实实验使用英文 VoiceBank-DEMAND，不是中文结果。
2. **数据规模限制**：正式对照只使用 128 条训练样本，不能代表全量训练能力。
3. **可懂度限制**：所有版本的平均 STOI 仍为负。
4. **验证可靠性限制**：原来的单说话人 64 条验证集未能预测 v4 的测试 STOI 优势。
5. **指标限制**：PESQ 因本机 Windows 缺少 MSVC 构建环境而记为 NaN。
6. **产品化限制**：尚无简单推理脚本、试听页面、桌面界面或安装包。
